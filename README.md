# EPOCH-7 · The Accelerated Calendar

**一个将现实时间加速映射为纪元时间的个人时间系统。**

EPOCH-7 是一个基于 7 倍时间倍率构建的个人时间系统。它尝试改变我们感知和组织时间的方式：现实世界过去 1 小时，EPOCH-7 的纪元时间便前进 7 小时。

它不改变现实世界的时间，而是建立一套独立的时间尺度，让每一天拥有更快的时间流速，以及一套清晰的时间区块结构。

---

## 1. 核心理念

在 EPOCH-7 中，时间不再只有现实世界中的一种计量方式。

我们同时使用两套时间：

- **Real Time（现实时间）**：现实世界正常流逝的时间。
- **Epoch Time（纪元时间）**：按照 7 倍速率推进的时间。

现实时间每经过 1 小时，纪元时间就经过 7 小时。

| 现实时间 | 纪元时间 |
|---|---|
| 1 秒 | 7 秒 |
| 1 分钟 | 7 分钟 |
| 1 小时 | 7 小时 |
| 1 天 | 7 天 |
| 7 天 | 49 天 |
| 30 天 | 210 天 |

EPOCH-7 的目标，是建立一个属于自己的时间坐标系，让时间成为可以观察、记录和管理的对象。

## 2. 时间计算原理

EPOCH-7 使用线性时间映射公式。

### 核心公式

```javascript
epoch_time = genesis_time + (real_time - genesis_time) * 7
```

其中：

- `genesis_time`：纪元创世时间。
- `real_time`：当前现实时间。
- `epoch_time`：计算得到的纪元时间。
- `7`：时间加速倍率。

### 举例

假设创世时间为：

```text
2026-11-16 00:00:00
```

当现实时间经过 24 小时：

```text
现实时间：2026-11-17 00:00:00
纪元时间：2026-11-23 00:00:00
```

也就是说，现实世界只过去了一天，而 EPOCH-7 的纪元已经向前推进了七天。

### 创世时间

EPOCH-7 的创世日期：

```text
2026-11-16
```

当前网页代码将创世锚点设定为设备本地时间：

```javascript
new Date(2026, 10, 16, 0, 0, 0, 0)
```

注意：JavaScript 中月份从 0 开始，因此 `10` 代表 11 月。

## 3. 七倍时间区块

EPOCH-7 将现实世界的一天划分为八个时间区块。

每个区块对应不同的时间阶段。区块用于组织现实生活，而纪元时钟则独立按照 7 倍速度推进。

### 每日时间结构

| 区块 | 时间 | 名称 |
|---|---|---|
| Genesis | 23:00 — 08:00 | 创世区块 |
| Block 1 | 08:00 — 10:00 | 区块 1 |
| Block 2 | 10:00 — 12:00 | 区块 2 |
| Block 3 | 12:00 — 14:00 | REST |
| Block 4 | 14:00 — 16:00 | 区块 4 |
| Block 5 | 16:00 — 18:00 | 区块 5 |
| Block 6 | 18:00 — 20:30 | 区块 6 |
| Block 7 | 20:30 — 23:00 | 区块 7 |

### 区块说明

- **Genesis Block（创世区块）**：23:00 至次日 08:00，跨越午夜的时间区块。
- **Block 1 — Block 2**：上午时间阶段。
- **Block 3 — REST**：12:00 至 14:00，休息区块。
- **Block 4 — Block 5**：下午时间阶段。
- **Block 6 — Block 7**：晚上时间阶段。

区块划分采用现实世界的本地钟表时间，而不是经过加速计算的纪元时间。

例如，现实时间为 11:00 时，当前区块应当是 Block 2，而不是根据纪元时钟重新判断。

## 4. 当前系统功能

目前 EPOCH-7 网页提供以下功能：

### 双时间显示

同时显示现实时间和纪元时间，让两套时间尺度能够直观对照。

### 7 倍时间加速

根据创世时间和当前现实时间，实时计算纪元时间。

### 时间差统计

展示现实世界与纪元时间之间的进度差异，包括：

- 现实经过时间
- 纪元经过时间
- 纪元领先现实的时间
- 纪元日期与日内进度

### 当前区块识别

根据设备当前的本地时间，自动识别所在区块，并高亮显示。

### 实时刷新

页面定期刷新时间数据，保持时间显示与当前时刻同步。

## 8. 部署方式

本项目使用 GitHub Pages 部署。

1. 打开 GitHub 仓库。
2. 进入 Settings。
3. 找到 Pages。
4. 在 Build and deployment 中选择 Deploy from a branch。
5. Branch 选择 `main`，目录选择 `/ (root)`。
6. 保存并等待 GitHub Pages 完成部署。

后续更新 `index.html` 或其他项目文件并提交到 main 分支，即可触发重新部署。

## 9. 项目发展方向

EPOCH-7 不只是一个时钟，也可以逐渐发展成一套个人时间管理系统。

未来可以围绕以下方向持续迭代：

- **时间记录**：记录每个区块实际完成的事情。
- **区块管理**：为不同区块设置目标、任务和用途。
- **时间统计**：统计不同时间区块的投入与产出。
- **历史记录**：回顾过去的纪元、日期和活动。
- **个人成长**：将时间记录与学习、运动、阅读等长期目标结合。
- **数据可视化**：通过图表观察时间分配和长期变化。

这些是未来的发展方向，并不代表当前版本已经实现。
